# 天机阁 1.5

天机阁是一个本地运行的中文实时资讯客户端。它聚合国内外官方机构、主流财经媒体、科技媒体和体育来源，支持自动刷新、中文翻译、关注词提醒、软件内正文阅读与自定义 RSS。

## 功能

- 聚合 76 个国内外资讯源
- 覆盖要闻、财经、股票、投资、经济、政策、科技、数码与体育
- 自动刷新、重大资讯桌面提醒和关注词订阅
- 国际资讯自动翻译为简体中文
- 软件内正文阅读与自定义 RSS
- 数据保存在本机，无需配置 API Key

## 安装

从 GitHub Releases 下载 `天机阁-1.5.0-Windows-x64.exe`，按照安装向导完成安装。

系统要求：Windows 10/11 64 位，并保持网络连接。当前安装包暂未进行代码签名，Windows SmartScreen 可能显示“未知发布者”，可在确认文件来源后选择“更多信息”与“仍要运行”。

## 开发

需要 Node.js 24 或更高版本。

```powershell
npm install
npm start
```

只启动本地 Web 服务：

```powershell
npm run serve
```

## 测试与打包

```powershell
npm test
npm run dist
```

安装包生成在 `dist` 目录。Windows 安装包使用 NSIS，支持选择安装目录，并创建桌面和开始菜单快捷方式。

## 数据

应用数据保存在 Electron 的 `userData` 目录。升级安装不会覆盖已有数据库、关注词、自定义 RSS 或启动设置。
